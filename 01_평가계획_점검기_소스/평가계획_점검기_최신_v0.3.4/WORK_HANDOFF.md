## 2. 송우중 평가계획 작업 현황

### 완료한 흐름

- 2026학년도 2학기 1·2·3학년 제출본을 과목별로 점검하고 1차·2차 검토본을 작성함.
- 오류 메모가 있는 과목은 수정 요청본으로, 수정 불필요 과목은 제출 불필요 상태로 구분함.
- 과목별 검토본과 학년별 합본을 만들고 목차의 과목명·쪽 번호에 이동 링크를 적용함.
- 검토 결과와 제출 교사명을 Google Sheet로 정리하고 Drive 검토본 링크를 연결함.
- 범교과 편성표는 연간 기준으로 대조하되, 사용자의 지시에 따라 1학기 재검토는 진행하지 않고 2학기 제출본의 누락 과목만 안내·메모 처리함.
- 평가 결과 분석 및 활용의 `00과 핵심역량` 잔존 문구를 실제 과목명으로 수정하고 완료 메모를 남김.
- 제출 후 수정된 영어·사회 등은 이전 검토본과 다시 대조하고 완료 메모를 정리함.

### 송우중 핵심 점검 기준

- 1·2학년: 2022 개정 교육과정, 3학년: 2015 개정 교육과정.
- 1학년 수행평가의 성취수준 A~E 표기는 정상이며 오류로 잡지 않는다.
- 정기시험 논술형 반영비율은 송우중 기준 **2% 이상**으로 판단한다. 다른 학교의 4% 기준과 섞지 않는다.
- 정기시험+수행평가 반영비율 합계는 100%여야 한다.
- 수행평가 한 영역의 반영비율은 30%를 초과하지 않는지 확인한다.
- 수행평가 전체 기본점수와 각 평가요소 최하점은 해당 만점의 20~40% 범위인지 확인한다.
- 백지 제출자 점수, 자발적 미참여자, 장기 미인정 결석자 점수 관계는 해당 학년도 송우중 학업성적관리규정 문구와 6번·8번 표를 함께 대조한다.
- 배점 급간은 특별한 사유가 없으면 균등해야 한다. 예: `10-8-6-4-2-1`은 마지막 감소 폭이 달라 수정 필수.
- 4번 평가의 종류와 반영비율 ↔ 6번 수행평가 세부기준의 영역명, 만점, 성취기준, 평가요소를 대조한다.
- 수행평가 시기 마지막 주까지 월별 계획표에 해당 성취기준이 처음 등장했으면 정상이다. 월 전체 병합 셀은 그 달의 모든 주차에 적용된 것으로 인정한다.
- 정기시험 시기가 있으면 월별 계획표에 정기시험 연계 표시가 있는지도 확인한다.
- 범교과는 별도 연간 편성표가 기준이며 프로그램의 일반 배포본에서는 자동 판단하지 않는다.

### 메모 작성 원칙

- 오류가 없는 부분에는 메모를 달지 않는다.
- 모든 메모는 오류가 있는 표의 관련 셀에 직접 붙인다.
- `◆ 오류 주제` 다음 줄부터 짧은 개조식으로 근거와 수정 방향을 쓴다.
- 성취기준 시기 오류는 수행평가 시기와 월별 계획표의 최초 등장 월·주를 함께 적는다.
- 배점 급간 오류는 실제 점수열과 권장 점수열을 함께 적는다.
- 이미 교사가 수정한 항목은 기존 메모 내용을 취소선 처리하고 `수정 완료`만 간단히 남긴다.
- 단순 오타만 직접 수정할 수 있다. 배점, 평가 내용, 성취기준처럼 교사의 판단이 필요한 값은 수정하지 않고 메모로 요청한다.
- 프로그램 메모를 그대로 배포하지 말고 AI 직접 검수로 오탐과 메모 위치를 확인한다.

## 3. 다른 학교 기준 분리

### 내촌중 3학년

- 정기시험 논술형 비율: 4% 이상.
- 기본점수 = 백지답안 제출자 점수.
- 자발적 미참여자 = 기본점수 - 1점.
- 장기 미인정 결석자 = 자발적 미참여자 - 1점.
- 평가요소별 최하점 20~40%도 확인한다.

### 내촌중 1·2학년 IB 평가계획

- 별도 제공된 `평가계획 점검표(1,2학년)`만 적용한다.
- 수행평가 영역 총점 기준의 기본점수 비율만 확인한다.
- 평가요소별 기본점수 비율은 확인하지 않는다.
- 기술·가정은 1·2학년 공용 파일 1개이며 1학년 검토본 폴더에 저장한다.

학교별 기준은 서로 섞지 않는다. 새 학교를 검토할 때는 논술형 최소 비율, 기본점수·미응시자 규칙, 자유학기 여부를 먼저 확인한다.

## 4. 현재 프로그램에 반영된 주요 개선

- 문서를 과목과 표준 섹터로 나누어 단계별로 점검함.
- 병합된 월별 성취기준 셀과 `9월 4주~11월 2주` 같은 줄바꿈 평가시기를 처리함.
- 반복된 상위 수행평가 영역을 묶어 점수·반영비율을 합산함.
- 4번↔6번의 영역명, 만점, 성취기준, 평가요소 비교를 보강함.
- 수행평가 배점 역전, 불균등 급간, 기본점수 범위와 미응시자 점수 관계를 점검함.
- 메모 앵커를 오류가 있는 실제 셀로 좁히고 분할 텍스트 앵커를 지원함.
- 생성한 HWPX를 한글 프로그램으로 실제 열어 검증하고, 열리지 않으면 손상된 메모본을 배포하지 않음.
- 범교과 시수에서 `시간`과 `차시` 표기를 모두 인식함.

## 5. 2026-08-19 확인 사항

- 내촌중 3학년 국어 검토 중, 6번 수행평가의 영역명이 4번과 다르고 만점이 비어 있을 때 기본점수 검사에서 중단될 수 있는 문제를 발견함.
- `extract_basic_score_rows_from_tables()`에서 비교 만점을 0으로 안전하게 보정하고 회귀 테스트를 추가함.
- 실제 HWPX 메모본은 ZIP 무결성만 보지 말고 `pyhwpx`로 한글 열기, 쪽 수, 메모 개수를 다시 확인해야 함.
- Drive 업로드 후에는 가능하면 업로드본을 다시 내려받아 한글에서 재검증한다.

## 6. 학교 PC에서 이어서 할 일

1. `깃허브 업데이트.bat` 실행 후 현재 브랜치가 `feature/desktop-eval-checker`인지 확인한다.
2. `py -3.14 smoke_test.py`와 `py -3.14 -m py_compile app.py checker.py`를 실행한다.
3. 실제 송우중 수정본이 새로 제출되면 이전 메모와 대조해 수정 완료·수정 필요를 구분한다.
4. 자동 점검 결과는 반드시 원문 표와 PDF 렌더링 또는 한글 화면으로 재확인한다.
5. 프로그램 수정 후 `WORK_HANDOFF.md`도 같은 커밋에서 갱신한다.

## 7. 현재 알려진 주의점

- HWPX XML 파싱 결과에는 병합 셀 때문에 같은 값이 반복되거나, `20점 (20%)`가 비정상 문자열처럼 보이는 경우가 있다. 화면 렌더링 확인 없이 오류로 확정하지 않는다.
- 평가요소 문구는 4번의 요약 표현과 6번의 상세 표현이 의미상 같을 수 있다. 단순 문자열 차이만으로 오류 처리하지 않는다.
- `HwpxMemoWriter`로 생성한 파일은 한글에서 다시 저장하면 호환성이 더 안정적이다.
- 한글 COM 자동화에는 Windows용 한글과 `pyhwpx`가 필요하다.
- 로컬 재검토 폴더 `08_평가요소_재검토_20260720`, `09_배포전_대조_20260721`에는 학교 자료와 출력물이 섞여 있으므로 GitHub에 통째로 올리지 않는다.
