# v0.3.4 테스트 보고

## 변경 요약

- 합본 HWPX 파일을 과목별로 분리할 때 기존에는 `table_rows`가 비어 있었으나, v0.3.4에서는 과목 텍스트와 대응되는 표 행을 함께 보존하도록 수정했다.
- HWPX 표 추출 시 `rowSpan`, `colSpan` 속성 순서에 덜 민감하게 처리하고, 병합 셀 값을 행/열 방향으로 채워 엑셀형 격자에 가깝게 복원하도록 수정했다.
- 표 행 매칭은 너무 넓게 잡히면 다른 과목 표가 섞이므로, 성취기준 코드와 특징적인 셀 값을 기준으로 보수적으로 필터링한다.

## 테스트 파일

- 송우중 2학년 합본 HWPX 파일
- 교육지원청 검토 결과 PDF의 송우중 2학년 지적사항과 대조

## 판단

v0.3.4는 v0.3.3보다 합본 파일의 표 기반 검토력이 개선되었다. 특히 과목 분리 후 표 행이 사라지는 문제가 완화되어 성취기준 관계 검사가 일부 살아났다.

다만 아직 표 행 매칭과 수행평가 세부기준 영역 분리가 완전하지 않아, 일부 과목은 상세 영역 수가 부족하게 추출된다. 다음 개선에서는 1번 월별 계획표, 4번 평가 반영비율표, 6번 수행평가 세부기준표를 표 단위로 먼저 분류한 뒤, 표 단위로 과목 구간을 연결하는 방식이 필요하다.
