# 평가계획 점검기 폴더 정리 안내

이 폴더는 평가계획 점검기 개발과 자료 보관을 위해 최소 구조로 정리했습니다.

## 현재 폴더 구조

- `01_평가계획_점검기_소스`
  - 평가계획 점검기 앱 소스 보관 폴더입니다.
  - `평가계획_점검기_기본_v0.3`: 기준이 되는 기본 버전입니다.
  - `평가계획_점검기_최신_v0.3.4`: 현재 가장 정확하다고 판단한 최신/주력 버전입니다.

- `02_평가계획_원본자료`
  - 실제 검토 대상 평가계획 원본 자료를 보관합니다.
  - 메모본, 엑셀검토표, JSON/CSV 결과물, MD 변환본은 정리 대상입니다.

- `03_성취수준_원본자료`
  - 2015/2022 성취수준 원본 자료를 보관합니다.
  - MD 변환본은 정리 대상입니다.

- `04_연수자료_양식_참고자료`
  - 연수자료, 양식, 참고문서를 보관합니다.
  - MD 변환본과 임시 결과물은 정리 대상입니다.

- `05_GitHub_개발도구_자료`
  - GitHub에서 받은 개발 도구와 보조 도구 자료를 보관합니다.
  - `tools/rhwp` 같은 도구성 자료는 삭제하지 않습니다.
  - `ai_review_knowledge`는 프로그램 실행 필수 의존이 아니라 삭제했습니다.

## 루트 보존 항목

- `.git`: Git 저장소 정보입니다. 삭제하지 않습니다.
- `.agents`, `.codex`: Codex 작업 환경 자료입니다. 삭제하지 않습니다.
- `.gitignore`: Git 업로드 제외 규칙입니다. 삭제하지 않습니다.

## 정리 원칙

- 결과물/output, 비교 결과, 메모본, 엑셀검토표, JSON/CSV 결과물은 삭제합니다.
- 중복 압축파일과 이미 압축 해제된 패키징 폴더는 삭제합니다.
- 평가계획 및 기타 자료를 MD로 변환한 파일은 삭제합니다.
- 앱 소스는 기본 버전 v0.3과 최신/주력 버전 v0.3.4만 유지합니다.
